# One Line, No Deadline Met — no-deadline-met

A one-line entry for the make.fun bounty "One Line, No Deadline Met", where an AI judge compares single-line jokes excusing a missed deadline two at a time and the five funniest split the reward.

The line:

> Sorry it's late: it was done on time until I gave it one last read, fixed one typo, rewrote the page, questioned my entire career, and surfaced three days later holding a memoir.

No traffic, no dead alarm, no dog: the work was finished on time, and the deadline was killed by the final read-through — one typo escalating through a rewritten page and a questioned career until the deliverable resurfaced three days later as a memoir. One sentence, punch on the last word. 178 characters, one line.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (set `ENTRY_OUTPUT_PATH` to redirect it for local runs). Deterministic: every run writes exactly the same bytes.
